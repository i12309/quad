# QUAD

QUAD — коллекция небольших браузерных игр, в которой всё игровое поле собрано из крупных квадратных «пикселей». Проект работает без сборщика: достаточно раздать каталог обычным HTTP-сервером.

## Запуск

Открывать `index.html` напрямую через `file://` не стоит: браузер блокирует загрузку JavaScript-модулей. Запустите сервер из корня проекта, например:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

Для проверки логики нужен Node.js 20 или новее:

```bash
npm test
```

## Игры

| Игра | Управление |
| --- | --- |
| Snake | Стрелки; собрать еду и не столкнуться со стеной или собой |
| Game of Life | ЛКМ — клетка; ПКМ или стрелки — перемещение поля |
| PingPong | Мышь двигает платформу |
| Arkanoid | Мышь двигает платформу; три жизни |
| Minesweeper | ЛКМ — открыть; ПКМ — поставить или снять флаг |
| SlidingPuzzle | ЛКМ по плитке рядом с пустой клеткой |
| TicTacToe | Локальная партия для двух игроков |
| Tetris | Стрелки — движение/поворот; пробел — быстрый сброс |
| Galaga | Мышь — движение; пробел — выстрел |
| PipeMania | После старта нажимать на трубы, соединяя `S` с `E` |
| Гонка | `←`/`→` или `A`/`D`; Enter/пробел — новая гонка после аварии |
| Песочная физика | `1` — песок, `2` — стена, `3` — ластик; рисование мышью |
| BlockCraft 2D | ЛКМ — добыть; ПКМ — поставить; `1`/`2`/`3` — материал |
| Простая стратегия | Рабочий → ресурс; замок — улучшить; ПКМ по замку — нанять |
| Живое поле | Старт/пауза управляют спокойной пиксельной анимацией |

Панель управления занимает отдельную область над игровым полем и не закрывает HUD или верхние клетки. В Game of Life, Minesweeper, SlidingPuzzle, TicTacToe, Tetris и PipeMania в панели доступен регулятор «Клетка»: он меняет размер квадратов без сброса текущей партии. Выбранное значение запоминается отдельно для каждой игры.

## Архитектура

- `src/GridManager.js` — единый рендер сетки через Konva и расчёт свободной игровой области.
- `src/Controls.js` — меню, переключение игр, масштаб и общий жизненный цикл.
- `game/BaseModule.js` — базовый контракт игры и безопасная очистка событий.
- `game/*.js` — игровые правила и формирование `selectedTiles`.
- `tests/` — детерминированные проверки правил, генераторов и жизненного цикла.

Каждый визуальный элемент хранится в `selectedTiles` под ключом `x,y`. Обычная клетка может содержать фон и текст, а `type: "text"` используется для HUD. При выходе в меню игра обязана остановить таймеры и удалить свои обработчики; это делает общий `BaseModule.destroy()`.
